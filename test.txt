2. AUTH — Login
------------------------------------------------------------------------

TEST-010  Valid login redirects to dashboard
  POST /login  { email: user@example.com, password: correct }
  Expected: redirect to /home, session authenticated

TEST-011  Wrong password is rejected
  POST /login  { email: user@example.com, password: wrong }
  Expected: redirect back with error on "email" field, guest session

TEST-012  Non-existent email is rejected
  POST /login  { email: nobody@example.com, password: anything }
  Expected: redirect back with error on "email" field

TEST-013  Empty fields are rejected
  POST /login  { email: "", password: "" }
  Expected: validation errors on both fields

TEST-014  Logout ends the session
  POST /logout  (authenticated)
  Expected: redirect to /, session cleared, now guest


------------------------------------------------------------------------
3. AUTH — Registration
------------------------------------------------------------------------

TEST-020  New user can register
  POST /register  { name, email (unique), password, password_confirmation }
  Expected: redirect to /home, row in users table, password hashed

TEST-021  Duplicate email is rejected
  POST /register  { email: already@taken.com, ... }
  Expected: validation error on "email" field, no new row created

TEST-022  Password confirmation mismatch is rejected
  POST /register  { password: abc, password_confirmation: xyz }
  Expected: validation error on "password" field

TEST-023  Missing required fields are rejected
  POST /register  { name: "", email: "", password: "" }
  Expected: validation errors on all required fields

6. EDGE CASES & SECURITY
------------------------------------------------------------------------

TEST-050  XSS in name field is stored escaped
  Register with name: <script>alert(1)</script>
  Expected: stored as escaped string, not executed in browser

TEST-051  SQL injection attempt in login is safely handled
  POST /login  { email: "' OR '1'='1", password: "anything" }
  Expected: normal login failure (no DB error, no bypass)

TEST-052  Oversized input is rejected
  POST /register  { name: (5000 chars), ... }
  Expected: validation error, HTTP 422 or redirect with error

TEST-053  Whitespace-only name is rejected
  POST /register  { name: "   ", ... }
  Expected: validation error on "name" field


------------------------------------------------------------------------
7. HOW TO RUN AUTOMATED TESTS
------------------------------------------------------------------------

  # Run all tests
  php artisan test

  # Run only Feature tests
  php artisan test --testsuite=Feature

  # Run only Unit tests
  php artisan test --testsuite=Unit

  # Run a specific test class
  php artisan test --filter AuthTest

  # Run with coverage report (requires Xdebug or PCOV)
  php artisan test --coverage
